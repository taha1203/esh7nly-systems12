# ESH7NLY — النسخة النهائية

واجهة عربية RTL لإدارة تفعيلات فودافون، المشتركين، الموردين، التجار المشترين، الحسابات المستحقة، الأرباح، رسائل واتساب، قائمة الانتظار، إعدادات الهوية، سجل العمليات، النسخ الاحتياطي والمزامنة.

## تشغيل سريع
1. فك ضغط الملف كاملًا مع الحفاظ على المجلدات.
2. ارفع محتويات مجلد `esh7nly_v4` إلى مستودع GitHub، ثم فعّل GitHub Pages من إعدادات المستودع.
3. افتح رابط الموقع. بيانات الدخول الافتراضية: `admin` / `1234`، ثم غيّرها فورًا من الإعدادات.
4. أضف الموقع للشاشة الرئيسية على الهاتف من قائمة المتصفح. يلزم HTTPS (مثل GitHub Pages) لتفعيل خصائص PWA.

## Firebase
قاعدة البيانات الموصولة حاليًا:
`https://esh7nly-62354-default-rtdb.firebaseio.com/`

المزامنة تستخدم Firebase Realtime Database SDK. يلزم ضبط قواعد Firebase بصورة آمنة قبل إدخال بيانات حقيقية.
**تنبيه أمني مهم:** تسجيل الدخول الحالي محلي داخل الواجهة وليس Firebase Authentication، لذلك لا يُعتبر حماية أمنية حقيقية. لا تستخدم قواعد قراءة/كتابة عامة مع بيانات العملاء. ملف `firebase-rules.json` آمن افتراضيًا ويمنع الوصول حتى تضبط المصادقة والقواعد. يوجد `firebase-rules-test-only.json` للاختبار المؤقت فقط، وهو يفتح القراءة والكتابة للجميع؛ لا تستخدمه مع بيانات حقيقية ولا تتركه مفعّلًا. الاستخدام الحقيقي يتطلب تفعيل Firebase Authentication وقواعد Database مقيدة للمستخدمين المصرح لهم.

## المميزات
- فودافون: تفعيل وإدارة أرقام يوم 11 ويوم 26، بحث وتصفية، مدفوع/غير مدفوع، وتحديد جماعي.
- تكلفة كل باقة وحساب المبيعات والتكلفة والربح.
- إدارة الموردين والتجار المشترين مع حساب عويس.
- تجهيز رسائل الحسابات على واتساب؛ لا يتم الإرسال تلقائيًا، بل تراجع الرسالة وترسلها بنفسك.
- قائمة انتظار مع موعد الحجز ومدة التنبيه قبل الموعد.
- تنبيهات تجديد، سجل عمليات، تغيير ألوان وهوية الموقع والخلفية.
- نسخة احتياطية JSON واستيرادها، وتصدير قائمة المشتركين بصيغة CSV المتوافقة مع Excel.
- ملفات PWA لتثبيت الموقع كتطبيق ويب على الهاتف؛ لا يتضمن هذا المشروع APK جاهزًا.
- اتصالات تظهر كقسم «قريبًا» ولا تنفذ تفعيلات اتصالات في هذه النسخة.

## ملاحظات
- الرسائل عبر واتساب تفتح محادثة جاهزة فقط؛ يلزم الضغط على إرسال يدويًا.
- تصدير CSV يحفظ قائمة المشتركين الحالية كاملة، بينما JSON يحفظ حالة النظام لإعادة الاستيراد.
- المزامنة الكاملة لحالة التطبيق قد تجعل تعديلات جهازين في نفس اللحظة تتعارض؛ خذ نسخة احتياطية دورية، وتجنب التعديل المتزامن على الأجهزة لحين ترقية المزامنة إلى مسارات مستقلة لكل سجل.
